C++ Programming Exercises
=========================

Collection of small C++ programs and data-structure examples used for practice.

Contents
- Many single-file exercises in the repository root (basic algorithms, control flow, I/O).
- Subfolders with grouped examples: `Array`, `Linked List`, `Binary Tree`, `Data_structure`, etc.

Build & Run
- Using MinGW g++ (Windows) — compile a single file:

```powershell
g++ -g path\to\file.cpp -o path\to\file.exe
.\path\to\file.exe
```

- VS Code: use the provided `C/C++: g++.exe build active file` task (Run: Terminal → Run Task).

Notes
- Files are intended as small practice programs; feel free to reorganize or add a top-level project structure.
